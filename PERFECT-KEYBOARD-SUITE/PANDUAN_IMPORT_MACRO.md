# ⌨️ Panduan Import File Makro (.4pk) ke Perfect Keyboard 9.4.6

Panduan langkah demi langkah cara memasukkan file database makro (`.4pk`) ke dalam software **Perfect Keyboard** untuk otomatisasi teks CS.

---

## 📂 Daftar File Makro yang Tersedia
1. **`1_KHUSUS_EVENT.4pk`** (~6.1 MB) — Template makro promosi, bonus, dan event khusus.
2. **`2_PK_ANTI_AUDIT_2025.4pk`** (~758 KB) — Database respon cepat Anti Audit edisi 2025.
3. **`3_PK_PENDAMPING_2025.4pk`** (~103 KB) — Template makro pendamping alur kerja CS harian.
4. **`4_PK_PIHAK_KETIGA.4pk`** (~16 KB) — Template makro koordinasi vendor & payment gateway pihak ketiga.

---

## 🚀 Cara Import ke Perfect Keyboard

### Langkah 1: Buka Aplikasi Perfect Keyboard
* Buka software **Perfect Keyboard 9.4.6** di komputer Windows Anda (icon kubus biru di system tray).

### Langkah 2: Buka File Makro
* Klik menu **`File`** di pojok kiri atas jendela Perfect Keyboard.
* Pilih **`Open Macro File...`** (atau tekan shortcut `Ctrl + O`).

### Langkah 3: Pilih File `.4pk`
* Arahkan ke folder `PERFECT-KEYBOARD-SUITE/macros/`.
* Pilih file makro yang ingin Anda gunakan (misalnya `1_KHUSUS_EVENT.4pk` atau `2_PK_ANTI_AUDIT_2025.4pk`).
* Klik tombol **`Open`**.

### Langkah 4: Selesai & Langsung Pakai!
* Seluruh daftar shortcut dan balasan otomatis akan langsung termuat di layar Perfect Keyboard.
* Anda cukup mengetik shortcut di browser/chat LiveChat, dan teks panjang akan otomatis terisi.

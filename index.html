Unduh Paket Aplikasi WORKSPACE-X

Siap Pakai • Bebas Compiler

Aplikasi desktop native Tauri v2 lengkap dengan Shift Control Center & Browser Extension Bridge.

⬇ Installer Windows (.exe, ~2.9 MB) ⬇ Portable Suite (.zip, ~3.7 MB)
✨ Fitur Unggulan & Kapabilitas Utama WORKSPACE-X
▸ START WORK 1-Klik: Otomatis memulihkan puluhan tab kerja dan grup tab di Opera/Chrome seketika.
▸ END WORK & Safe Logout: Tutup seluruh tab kerja dalam 1-klik dan arahkan ke logout Google resmi untuk keamanan PC shift.
▸ Shift Control Center: Live timer durasi bertugas & pengingat istirahat mata berkala 20 menit (20-minute eye break).
▸ Catatan Operan (Handover Notes): Buat memo penting untuk shift berikutnya lengkap dengan quick snippet & tombol salin format.
▸ SOP Shift Checklist: Daftar periksa pra-shift dan pasca-shift untuk memastikan kepatuhan prosedur operasional.
▸ 100% Local-First Architecture: Database SQLite tersimpan lokal, tanpa kirim data ke cloud, zero password/cookie retention.

🛠️ Panduan Pemasangan & Penggunaan (Pilih Salah Satu Metode)

Metode 1: Menggunakan Windows Installer Setup (.exe) — Rekomendasi PC Tetap / Kantor
Ukuran ~2.9 MB
1

Unduh & Jalankan Workspace-Hub-Setup.exe

Klik tombol ⬇ Installer Windows (.exe) di atas. Setelah selesai mengunduh (~2.9 MB), klik 2x file Workspace-Hub-Setup.exe → ikuti wizard instalasi standar (Next → Install).

2

Shortcut Desktop & Start Menu Siap Digunakan

Aplikasi akan otomatis membuat shortcut resmi di Desktop Windows dan terdaftar di Start Menu Windows (dapat dicari kapan saja dengan mengetik "Workspace-Hub" di kolom pencarian Windows).

3

Pasang Ekstensi Browser Bridge (Hanya 1x)

Buka Opera/Chrome → akses chrome://extensions atau opera://extensions → aktifkan Developer mode → klik Load unpacked → pilih subfolder extension yang disertakan di paket WORKSPACE-X.

Metode 2: Menggunakan Portable Suite (.zip) — Rekomendasi PC Shift / Tanpa Akses Administrator
Ukuran ~3.7 MB
1

Unduh & Ekstrak WORKSPACE-X.zip

Unduh file WORKSPACE-X.zip (~3.7 MB) lalu ekstrak folder WORKSPACE-X-PORTABLE di desktop, dokumen, atau flashdisk komputer Anda.

2

Jalankan 1-KLIK-PASANG-EKSTENSI.bat (5 Detik)

Klik 2x file 1-KLIK-PASANG-EKSTENSI.bat. Alamat folder ekstensi otomatis disalin ke Clipboard komputer Anda dan browser langsung terbuka. Di browser: Nyalakan Developer mode → Klik Load unpacked → Tekan Ctrl + V di kotak dialog folder → Klik Select Folder.

3

Jalankan 1-KLIK-JALANKAN.bat

Klik 2x file 1-KLIK-JALANKAN.bat (atau langsung file Workspace-Hub.exe). Aplikasi langsung aktif seketika tanpa instalasi, dan database otomatis tersimpan di folder data/ portabel Anda.

🛡️
Keamanan Multi-Shift Terjamin: WORKSPACE-X dirancang khusus untuk komputer kantor bersama. Aplikasi tidak pernah menyimpan password atau token sesi. Ketika shift berakhir, selalu gunakan tombol END WORK di dalam aplikasi untuk menutup seluruh tab kerja dan keluar dari akun Google secara aman.

Unduh Paket Ekstensi OCR Suite v2.7

Updated v2.7

Paket terbaru dengan Antrean 4-Kolom, Instant Google Sheets Sync, Safety Lock 100%, dan link interaktif di Dashboard.

⬇ Download EXTENSION-SCATTER-SMJ.zip (~20.7 MB)
✨ Pembaruan Fitur Terbaru (v2.7)
▸ Antrean Cerdas 4 Kolom: UserID [TAB] KodeTiket [TAB] Livechat [TAB] Screenshot.
▸ Instant Sheets Sync: Status Approved/Rejected langsung terkirim seketika dengan auto-retry 3x.
▸ Safety Lock 100%: Verifikasi ganda angka scatter sebelum klik simpan tiket bonus.
▸ Auto-Spacing Pintar: Otomatis beri spasi saat paste antrean di popup/dashboard.
1

Ekstrak Arsip ZIP

Ekstrak file EXTENSION-SCATTER-SMJ.zip. Di dalamnya terdapat subfolder otoscatter yang berisi seluruh binary WASM, trained data, dashboard, dan service worker ekstensi.

2

Load Unpacked di Browser Chrome / Opera

Buka chrome://extensions → Aktifkan Developer mode (kanan atas) → Klik Load unpacked → Pilih folder otoscatter hasil ekstrak.

3

Buka Dashboard & Konfigurasi URL

Buka dashboard melalui ikon ekstensi atau akses file otoscatter/dashboard.html. Masukkan URL Admin (protokol https:// otomatis dilengkapi jika terlewat) dan URL Webhook Google Sheets untuk sinkronisasi otomatis.

4

Deploy Antrean & Monitor Ekstraksi Visual

Paste antrean transaksi dengan format UserID [TAB] KodeTiket [TAB] Link Livechat [TAB] Screenshot. Tekan Deploy Scanner. Dashboard 8-kolom akan memindai scatter secara presisi, menyediakan tautan langsung 💬 Buka Livechat & 📸 Lihat Bukti SS, serta mengirim status real-time ke Google Sheets.

# 📸 SMJ Lab — Auto Screenshot & Discord Webhook Logger

Aplikasi otomatisasi tangkapan layar (screenshot) berkecepatan tinggi untuk pencatatan log operasional CS, dilengkapi deteksi penekanan tombol **ALT+TAB** dan pengunggahan instan ke **Discord Webhook**.

---

## ⚡ Cara Menjalankan Aplikasi (Hanya 1 Klik)

1. Buka folder ini (`AUTO-SCREENSHOT-LOGGER`).
2. Klik 2x file: **`1-KLIK-JALANKAN.bat`**.
3. Aplikasi antarmuka modern akan langsung terbuka.

---

## 👤 Pengaturan Awal (Mudah dengan Dropdown)

1. Buka tab **🔧 CONFIGURATION**.
2. Pada bagian **"Pilih Nama Agen CS (Auto-Fill Webhook)"**, klik dropdown dan pilih nama Anda (contoh: `SERGIO MICHAEL JORDY` / `ROMEO GINTING` / `ARIE HADIYANTO` dsb.).
3. Link Webhook Discord Anda akan **otomatis terisi**.
4. Atur interval screenshot (default: 2 detik).
5. Klik **💾 SAVE SETTINGS**.
6. Klik **🚀 START SERVICE** untuk memulai.

> **Tips**: Saat service aktif, Anda dapat menutup jendela GUI dan service akan tetap bekerja diam-diam di background tanpa membebani komputer.

---

## ⏹️ Cara Menghentikan Service
- Buka aplikasi dan klik **⏹️ STOP SERVICE**, atau
- Klik 2x file **`UNINSTALL_SERVICE.bat`** untuk menghentikan seluruh proses di background.

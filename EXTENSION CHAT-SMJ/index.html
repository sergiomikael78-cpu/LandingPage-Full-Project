Konfigurasi Sistem Kelola Ekstensi

Untuk memastikan seluruh arsitektur skrip internal di atas dapat berkoordinasi, sinkron, dan saling bertukar data secara instan, Anda wajib mengaktifkan izin-izin berikut pada panel setelan Tampermonkey Anda:

1. Developer Mode (Izin Skrip Pengguna)

Mengaktifkan izin dasar integrasi untuk menyuntikkan skrip premium ke LiveChat.

2. Izin Mode Samaran (Incognito Mode)

Mempertahankan fungsi pengawasan SLA dan pelacakan durasi saat bekerja di tab Incognito.

3. Izin Akses URL Berkas (Access to File URLs)

Mengizinkan koordinasi real-time antara pustaka aset lokal dengan browser agen.

💡 Prosedur Aktivasi: Klik kanan ikon Tampermonkey di pojok kanan atas browser > Pilih Kelola Ekstensi (Manage Extension) > Temukan ketiga izin di atas > Nyalakan Seluruh Toggle Switch Menjadi Biru / Aktif.

Langkah Pasca Instalasi

1

Setelah mengklik tombol pasang emas pada keenam kartu di atas, klik tombol Install / Reinstall pada tab konfirmasi ekstensi Tampermonkey yang otomatis terbuka.

2

Buka halaman aplikasi LiveChat Anda, atau lakukan penyegaran penuh halaman (Refresh / F5) untuk memulai sinkronisasi metrik data.

3

Sistem terintegrasi kini aktif berjalan sepenuhnya di latar belakang LiveChat Anda, mengawasi SLA, memotong spam, dan mendata durasi secara otomatis.
